An exhaustive search over a combinatorial keyspace, mapped onto a GPU so each thread reconstructs its own candidate from a global index. Paired with a small neural cost model trained on measured runtimes, which fits the log-linear blow-up as search length grows and extrapolates how long longer searches would take.
